# 1.0.0

- Initial Release
- **No Orb Pulse** — Disables the pulsing effect on orbs
- **Orb Pulse Size** — Fine-tune the orb pulse size when not fully disabled
- **No Circles** — Removes all circle wave effects during gameplay
- **Force 16:9** — Adds black letterbox bars for a consistent 16:9 aspect ratio
- **Auto Click** — Simulate a key press at a configurable level percentage (useful for muting Discord, etc.)
- Interactive key recording via pause menu button
- Pause menu settings button for quick access
- Cross-platform support: Windows, macOS, iOS, Android
