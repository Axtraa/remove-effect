# Remove Effect

Disable certain visual effects in Geometry Dash.

## Features

- **No Orb Pulse**: Disables the pulsing effect on orbs
- **No Circles**: Disables all circle wave effects
- **Force 16:9**: Adds black letterbox bars to display the game in 16:9 aspect ratio

## Settings

All features can be toggled on/off in the mod settings menu in-game, accessible via the pause menu button.
